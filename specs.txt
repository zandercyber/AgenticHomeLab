## 4. Lab Infrastructure Objectives

The equipment will establish a dedicated cybersecurity lab environment supporting:

- Network configuration and administration.
- Network traffic analysis and packet inspection.
- Firewall configuration and network segmentation.
- Virtualization and isolated testing environments.
- Linux and Windows server administration.
- Controlled penetration testing.
- Capture the Flag (CTF) exercises.

All testing will be conducted within authorized and isolated environments.
